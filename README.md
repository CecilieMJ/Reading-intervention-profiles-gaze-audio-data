# Reading-intervention-profiles-gaze-audio-data
Code used for a Master Thesis project investigating reading intervention profiles among 4th grade Danish students using gaze and audio data. 

The specific data used for this project is not publically available.

The code has a filtering and analysis specific to the used dataset.

Furthermore it includes data overview, feature engineering, imputation and scaling, PCA, clustering, validation and profiling, 6D distances, statistics, and a word breakdown analysis.
